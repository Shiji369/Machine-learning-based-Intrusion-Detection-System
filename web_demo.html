ML-IDS

Machine Learning Based Intrusion Detection System

1. Manual Network Flow Analyzer

Enter network-flow features and submit them for analysis. Presets are example inputs for demonstration and do not represent live network traffic.

2. CSV Dataset Evaluation

Upload a CSV containing the 41 NSL-KDD feature columns and a label column named attack_type or label. The backend evaluates the dataset using Random Forest, Isolation Forest, and the Combined model.
